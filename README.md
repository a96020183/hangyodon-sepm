# Hangyodon SEPM Study Flight

畀 Blue 嘅 Hangyodon 陪讀小遊戲：按 SEPM 原本第 0–11 主章節選 topic，做英文 MCQ、儲 XP、重溫錯題同收集徽章。手機同電腦瀏覽器都可以用。

直接使用：[Hangyodon 陪你飛](https://a96020183.github.io/hangyodon-sepm/)。

先揀機型，再揀章節練習：**Boeing 777、Airbus A321neo、A330、A350 或 Boeing 747 Freighter**。每個機型都會篩選相應專屬題目及適用嘅通用／共用程序；章節、未做題、新增題、錯題收藏及小節練習均按所選機型出題。目前預設 **Boeing 777**，777 配置可另外揀 773P、773A/K 或 773J；未確定就用全部 777 配置。每個機型都有相應第 10 章程序捷徑。「全書混合」保留全部 11,117 題。切換機型會保留 XP、錯題及原有紀錄；通用／共用題目的同一答案紀錄會共用，其他機型錯題會在切換到該機型時顯示。條件、註冊號及機型例外仍按每題原文核對。

首頁可按考試內容揀**細 topic**，支援搜尋原文名稱、小節編號及多選；一般出題、未做題、新增題同錯題收藏都會跟所選範圍。Boeing 777 的 **Door Emergency Operation** 捷徑會揀 § 10.4.2.2.4（Doors 1, 2, 4 & 5）及 § 10.4.2.3.4（Doors 3），亦可只揀其中一組門。題目以原手冊小節歸類；這個捷徑不表示完整考試範圍，相關 evacuation duties 可按需要另選。細 topic 選擇按機型保存，第 0–11 大章節仍可選。

每個所選範圍會自動提供 **3 分鐘預習**及 **Flash Cards**。預習從不同小節抽取最多 10 段不重複英文原文，先建立流程地圖；Flash Cards 直接以現有題目、正確答案及手冊引文生成，不需要使用者逐張建立、輸入答案或設定 deck。翻卡時按回想難度揀「很難／馬上重溫」、「有點難／明天再溫」或「輕鬆／遲啲再溫」，系統便按結果安排下次重溫。預習、翻 5 張卡及做 5 題 MCQ 組成每日三格任務，每格 +5 XP；所有紀錄可隨進度備份匯出及匯入。

「收藏錯題」會按目前機型及細 topic 顯示相應錯題，並可直接開始最多 20 張 **錯題 Flash Cards**。翻卡不會自行移除錯題；完成後可重挑戰同一批 MCQ，仍須連續答啱兩次才會移出收藏。

「進度／弱點」提供 **弱點雷達**，分別排列大章節及最細原文 topic 的 Top 5。錯誤率按「答錯次數 ÷ 該 topic 總作答次數」計算，並列出作答樣本；只答過 1–2 次會標示樣本較少。分析只計目前機型，可一按以 5 題 MCQ 挑戰指定弱點。

目前 **11,117 題**，由原有 96 題擴充。已盤點 667 頁手冊、798 個編號目錄項目；**600/600 個最細目錄小節**及 **547/547 頁學習內容**均至少有一道附來源的題目，包括附錄 A、B、C。其餘頁面為 95 頁明示留白、23 頁目錄／修訂紀錄和 2 頁出版控制。

今次新增 **2,306 題**，補充完整 SOP 步驟、209 項設備位置資料、機型差異、急救用品、DGR 完整條款及欄位、PPE 穿脫與安全清單；首頁可按「只練新增題」集中練習。72 行培訓矩陣另按全部六個勾選／空白欄位核對。

覆蓋代表每個小節及內容頁均有題目，並不代表每一個事實、圖示標籤或 SOP 步驟均已被考核。完整程序、條件及例外仍須閱讀原手冊。首頁「全書覆蓋清單」列出各小節題數，亦可搜尋及練習指定小節。

## 題目及來源

題幹、選項和原文引用使用 PDF 英文；介面及預設收起的輔助提示使用廣東話。題型包括情境／知識題、原文填詞、原生 briefing 完整答案、設備數量及培訓矩陣。

每題正確選項均有原文依據。文字題核對完整原句；表格題按原頁 cell 座標、合併格及勾選欄位核對；掃描表格／圖示題人工對照原圖，並保留來源裁圖。培訓課程組合題以原有欄名串列完整勾選集合，標示為表格解讀，並非連續原句。答題後顯示來源類型、英文證據、章節及 PDF 頁碼。來源版本為 FOP_SEPM_20260824.pdf，24 Aug 2026，Rev. 11。[覆蓋報告](site/coverage-report.json)可查看逐節及逐頁盤點。

按 **Open your local manual** 可選取自己裝置上的 PDF，网站核對 SHA-256 與題庫來源一致後開啟引用頁面，檔案不會上傳。重新整理後需重新選取；部分手機可能忽略指定頁碼，可手動輸入畫面列出的 PDF 頁碼。

完整 PDF 留在本機，網站包含題目、引用摘錄及部分原頁裁圖。

## 溫習紀錄與部署

「全題進度」按所選章節的 PDF 頁碼順序練習未答過的題，做過的題不再抽入此模式。已做題數與熟習題數分開顯示，錯題仍需重溫。每回合最多 20 題，完成後可直接繼續下一批。

XP、錯題及徽章存於目前瀏覽器 localStorage；不同裝置各自保存。航程手帳提供匯出／匯入 JSON 紀錄，搬到另一裝置時會核對手冊指紋。匯入取代目前紀錄，格式錯誤則保留原有紀錄。每題每日首次答對獲得 10 XP，以香港日期計算；錯題連續答對兩次才移出收藏。原有 8,811 題 ID 與手冊指紋保持不變，既有進度保留。

GitHub Actions 在推送 main 後部署 site/。網站無 API key 或後端；Hangyodon 圖嵌入 HTML，來源裁圖在 assets/references/ 按需載入。修改靜態網站後推送即可部署。

Hangyodon 角色屬 Sanrio；本網站為個人非官方溫習作品。XP 及徽章是練習紀錄，不是操作資格或官方考核結果。
